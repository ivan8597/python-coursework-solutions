# Решение задачи `generate_report`

## Идея расчета

Отчет строится на дату **1 марта 2023 года**, а интервал между платежами равен **183 дням**.

Для каждого студента программа:

1. Находит его данные во втором и третьем списках по `student_id`.
2. Проверяет, наступила ли дата `expected_payment_date` к 1 марта 2023 года.
3. Если платеж просрочен, вычисляет количество просроченных платежей по формуле:

```text
количество просроченных платежей =
(1 марта 2023 − дата ожидаемого платежа) // 183 + 1
```

Например, если платеж ожидался 3 февраля 2022 года, к 1 марта 2023 года просрочены даты 3 февраля 2022, 3 августа 2022 и 3 февраля 2023. Получается 3 платежа.

Для студента с рассрочкой `Y` один платеж считается как `installment_amount / 6`, а долг равен количеству просроченных платежей, умноженному на размер одного платежа. Сумма ограничивается значением `left_to_pay`, чтобы долг не превышал остаток всей рассрочки.

Для студента без рассрочки `N` долгом считается `one-time_payment`, если ожидаемый платеж уже просрочен.

## Код

Файл с готовой реализацией находится в приложении `student_debt_solution.py`.

Ключевой вызов после получения данных из Google Sheets выглядит так:

```python
generate_report(sheet1_data, sheet2_data, sheet3_data)
```

После вызова рядом с программой создается файл:

```text
student_debt_report.txt
```

Каждая строка имеет требуемый формат:

```text
Студент Иванов И.И. - долг 100000 рублей
```

## Как получить три списка через `gspread`

```python
sheet1 = client.open("название_таблицы").worksheet("Лист1")
sheet2 = client.open("название_таблицы").worksheet("Лист2")
sheet3 = client.open("название_таблицы").worksheet("Лист3")

sheet1_data = sheet1.get_all_records()
sheet2_data = sheet2.get_all_records()
sheet3_data = sheet3.get_all_records()

generate_report(sheet1_data, sheet2_data, sheet3_data)
```

`get_all_records()` возвращает список словарей. Например, одна строка первого листа выглядит примерно так:

```python
{
    "student_id": "101",
    "student_name": "Иванов И.И.",
    "installment (Y/N)": "Y"
}
```

## Почему используются словари для поиска

В начале функции записи из `sheet2` и `sheet3` превращаются в словари по `student_id`:

```python
payments_by_id = {str(row["student_id"]): row for row in sheet2}
amounts_by_id = {str(row["student_id"]): row for row in sheet3}
```

Это позволяет быстро найти данные студента, не перебирая второй и третий списки заново для каждого человека.

## Важные детали реализации

Функция принимает несколько распространенных форматов дат: `YYYY-MM-DD`, `DD.MM.YYYY`, `DD.MM.YY` и некоторые варианты со слешами. Числа могут содержать пробелы или десятичную запятую.

Для денежных расчетов используется `Decimal`, а не обычный `float`. Это уменьшает риск ошибок округления. В итоговый файл записываются целые рубли с отбрасыванием копеек, что соответствует виду эталонного ответа.

Если у студента нет записи во втором или третьем листе, программа пропускает его, поскольку рассчитать долг без даты и суммы невозможно.

Проверка выполнена на небольшом тестовом наборе. Например, для даты ожидаемого платежа 3 февраля 2022 года и суммы рассрочки 600000 рублей программа считает три просроченных платежа по 100000 рублей и записывает долг 300000 рублей.

## Запуск

Сохраните файл `student_debt_solution.py`, затем импортируйте функцию или вставьте ее в ячейку ноутбука. После получения трех списков выполните:

```python
generate_report(sheet1_data, sheet2_data, sheet3_data)
```

Затем проверьте созданный файл:

```python
with open("student_debt_report.txt", encoding="utf-8") as file:
    print(file.read())
```

> Примечание: в решении предполагается, что для рассрочки общая сумма `installment_amount` распределяется на шесть равных платежей. Это следует из условия о шестимесячном периоде платежей.
