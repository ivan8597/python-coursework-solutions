## Основные определения

**Retention 15-го дня** — доля пользователей январской когорты, которые вошли ровно через 15 дней после регистрации. День регистрации считается нулевым днем, поэтому используется дата `registration_date + 15 дней`.

**Rolling retention 30-го дня** — доля пользователей январской когорты, которые вошли в систему в 30-й день или в любой последующий день. Это отличается от обычного retention: для обычного retention нужен вход ровно в конкретный день, а rolling retention учитывает любой вход после этой даты.

**Lifetime** — дискретный интеграл от n-day retention. В реализации для каждого возраста от 0 до максимального возраста в данных считается retention как доля всех пользователей, активных ровно в этот день жизни. Затем эти значения складываются.

**Churn rate 29-го дня** — доля пользователей, которые не вернулись в 29-й день или позже. Поэтому расчет выполнен как дополнение к rolling retention 29-го дня:

```text
churn_29 = 1 - rolling_retention_29
```

Здесь результат хранится в долях, а не в процентах, поэтому значение равно `0.509`, то есть 50.9%.

**DAU** — количество уникальных пользователей за день. **WAU** — количество уникальных пользователей за календарную неделю. **MAU** — количество уникальных пользователей за календарный месяц.

Повторные входы одного пользователя в один день не увеличивают DAU, поэтому данные предварительно дедуплицируются через множества `set`.

## Важные детали

Входные файлы разделены точкой с запятой, поэтому CSV читается вручную с помощью стандартных средств Python и метода `split(';')`. Внешние библиотеки вроде pandas не используются.

Январская когорта определяется как пользователи с `registration_date` в январе 2021 года. Данные активности охватывают 2021 год, а декабрьские метрики рассчитываются по декабрю 2021 года.

Средний MAU считается как среднее число уникальных пользователей по всем календарным месяцам, присутствующим в данных. Средний WAU считается как среднее число уникальных пользователей по календарным неделям понедельник–воскресенье. Средний DAU считается как среднее количество уникальных пользователей по всем дням, в которые были события.
